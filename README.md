A deadpan one-star review of an everyday essential — the sun — filed in earnest against a thing that cannot be fixed.

## The review

> One star. The sun turns up late all winter, leaves early every evening, and has never once apologised.

## How it works

`main.py` (Python standard library only) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). It is deterministic: every run produces byte-identical output.

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
